# IT Systems &amp; Security Resume

A responsive, print-friendly resume website with a separate personal interests page.

## Pages

- `index.html` — resume, experience, education, certifications, and core competencies
- `interests.html` — hiking, gardening, photography, painting, and sketching

## Preview locally

From the repository root, start a local static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Published site

The repository uses GitHub Pages for deployment.
